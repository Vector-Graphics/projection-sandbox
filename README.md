This is a software for tinkering with map projections. The code was largely generated by ChatGPT and stitched together by me. I published this because all the existing software for converting between map projections wasn't capable enough (it didn't support specifying custom projections, or reverse projections, or it cropped things in a way that made projections difficult to visualize).

The software supports converting an Equirectangular source image to any projection, and converting an image in a given projection to Equirectangular, and therefore can be used to convert between any two map projections.

The app supports javascript in the X and Y formula windows, and also supports non-`Math` aliases of `Math` functions (i.e. sin, max, etc)

* Output resolution: The maximum dimension of the output image.
* Graticules: The density of graticules per 90 degree interval.
* Solver quality: The resolution of the base grid the app uses to compute projections. Increase this if you're getting weird blank artifacts.
* Preset: Various pre-existing projections to choose from.
* Show graticule: Show or hide the grid lines on the map.
* Show distortion: Show or hide approximate Tissot's indicatrices that show the distortion in the map projection.


I have included some idiosyncratic projections in the software. They are as follows:

* Walker I (lenticular), shape-favoring, designed after the common features of AI-generated images of "world maps"
* Walker II (lenticular), area-favoring, intended to be part of the same 'family' of projections as Walker I

* Walker pseudoequivalent (cylindrical), area-favoring, approximates Gall-Peters away from the poles but reduces shape distortion at the cost of imperfect area preservation
* Walker pseudoconformal (cylindrical), shape-favoring, approximates Mercator away from the poles but has finite poles, and thus only preserves shape imperfectly. Best presented with a vertical stretch of about 1.3257.

* Majestaz (cylindrical), shape-favoring, approximates Mercator near the equator with a 3rd-degree polynomial and is therefore easy to compute. Devised by my friend Majestaz.

* FPMW (pseudocylindrical), area-favoring, approximates Mollweide near the equator without being transcendental and keeps the same elliptical shape. Imperfect but accurate area preservation.
